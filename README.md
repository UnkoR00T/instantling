# Instantling - Automated software for instaling

## [PL] Użycie
1. Przejdź do sekcji [releases](https://github.com/UnkoR00T/instantling/releases/latest), i pobierz wersję dla twojego systemu. (Dla windowsa szukaj zakończenia pliku .exe).
2. Przejdź do folderu w którym znajduję się pobrany plik i go odpal. \
Windows: Kliknij plik dwa razy szybko \
Linux: `./instaling-bot-<system>`
3. Wypełnij pola w oknie które się pojawiło.
4. Kliknij start, dane logowania zostaną zapisane (chyba że opcja zapamiętania została odznaczona).

## [ENG] Usage
1. Go to the releases section and download the version for your system (for Windows, look for the .exe file extension).
2. Go to the folder containing the downloaded file and run it: \
Windows: Double-click the file. \
Linux: Run ./instaling-bot-<system>
3. Fill in the fields in the window that appears.
4. Click Start; your login credentials will be saved (unless the option to remember them was unchecked).
