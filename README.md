# instantling
 
### About
InstantLing is bot for instaling.
Made using Python and Selenium

### Instalation
To install this you need: Python 3.0 or higher.
1. `git clone https://github.com/AlexYTGamePL/instantling.git` or download the code as ZIP file and extract to any directory.
2. `cd instantling` or open the folder with files
3. in `instant.py` edit the login and password variables and save the file.
4. run start.bat file and wait
  or
   `pip install selenium` then `python instant.py`
5. Enjoy
